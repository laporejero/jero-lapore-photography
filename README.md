# jero-lapore-photography
📸 Personal Photography Website

🔗 Live Demo: https://laporejero.github.io/jero-lapore-photography/

A responsive photography portfolio and journal website built with React and Vite to showcase visual storytelling through a clean, editorial-inspired interface. The project focuses on presenting photography as the primary visual element while maintaining a scalable and modular front-end architecture.

The design uses a typography-driven layout system with minimalist styling, structured spacing, and dynamic visual themes. Each section is intentionally separated to create a focused browsing experience without unnecessary distractions.

🧱 Features
- Responsive photography gallery with CSS Grid layouts
- Interactive lightbox image preview system
- Journal section with dynamic article routing
- Dark mode theme toggle using React context
- JSON-powered image and content management
- Modular component architecture for scalability
- Typography-focused editorial design system
- Fully responsive layout across desktop, tablet, and mobile devices

🛠️ Tech Stack
- React.js
- Vite
- React Router DOM
- JavaScript (ES6+)
- CSS Modules
- CSS Variables (design system)

🧠 What I Learned

This project improved my understanding of component-based architecture in React and how to structure scalable front-end applications using reusable components and organized folder systems. I also gained experience working with React Router to create dynamic page navigation and route-based rendering.

A major focus of the project was building a flexible design system using CSS variables for typography, spacing, and theme management. Implementing dark mode support with React context also helped strengthen my understanding of global state handling and UI theming strategies.

Working with JSON-based content management allowed me to separate presentation from data, making the gallery and journal sections easier to maintain and expand over time.
